# Verdhana AI

12 AI specialists for marketers. Built with Next.js 14, OpenRouter, Supabase.

## Quick start

```bash
npm install
cp .env.example .env.local
# fill in your keys
npm run dev
```

Visit http://localhost:3000

## Deploy

Push to GitHub, import to Vercel, add env vars, done.

## Tech stack

- Next.js 14 (App Router)
- TypeScript + Tailwind CSS
- OpenRouter (AI inference)
- Supabase (auth + database — coming soon)
- Trigger.dev (24/7 background jobs — coming soon)
- Upstash Redis (queue — coming soon)
- Resend (transactional email — coming soon)
