# Verdhana AI

Platform 12 AI specialist untuk menghasilkan marketing copy berkualitas tinggi — cepat, konsisten, dan siap pakai.

🔗 **Live:** [verdhanaai.com](https://verdhanaai.com)

## Tech Stack

| Layer | Teknologi |
|---|---|
| Frontend | Next.js 14 |
| Database | Supabase |
| AI Router | OpenRouter |
| Hosting | Vercel |
| Email | Resend |
| Cache & Rate Limit | Upstash Redis |

## Getting Started

```bash
npm install
npm run dev
```

## Deploy

```bash
npx vercel --prod
```
